優先度 01成長ループ

招待リンクは「登録の壁」ではなく、体験の入口にする

リンクを開いた瞬間、ログインなしで旅程が見える。編集するときだけログインへ誘導。LINEに貼るとリッチなカバーカードが自動生成され、「ちゃんとしたサービス感」がクリック率を変えます。

  • 0クリック閲覧で最大の離脱ポイントを撤去
  • リッチOGP（カバー＋日程＋メンバー）でLINE共有を最適化
  • 1トリップ＝2〜6人。招待そのものが K>1 の成長エンジン

優先度 02リテンション

「行きたい」を貯める場所が、旅と旅の“間”を埋める

Instagram・記事で見つけたスポットを、旅行の予定がなくてもクリップ。既存の scraps テーブルを活かせます。貯めたクリップは新しい旅程へドラッグで流し込むだけ。「計画が一瞬で埋まる」がアハ体験に。

  • 予定がなくても開く理由＝平常時のアクティブ化
  • タグで「沖縄」「グルメ」に整理、旅の資産として蓄積
  • クリップ → 旅程へワンタップ変換で計画コストを最小化

優先度 03コア体験・最大の差別化

予約メール/URLを貼るだけで、旅程が自動でできる

航空券やホテルの確認メールを貼ると、日時・場所・予約番号を抽出してスケジュールに自動配置。手入力ゼロ。ここは LLM で最も差別化できるポイントで、「LINE＋メモ帳」を捨てさせる決定打になります。

  • 入力の手間ゼロ＝“これがないと無理”の瞬間を作る
  • 便名・時刻・予約番号を構造化して当日にワンタップ表示
  • Claude / LLM を活かした、模倣されにくいコア価値

優先度 04獲得ループ

旅行後のアルバムが、次の誰かを連れてくる

終わった旅を1枚のWebページとしてシェアURL化。参加していなかった親や友人が見て「私も次使いたい」と入ってくる、第2の新規獲得ループになります。訪れた場所の記録がSNS共有欲も刺激します。

  • 非利用者へのリーチ＝招待とは別経路の獲得
  • スポット数・写真・メンバーを1枚に凝縮した共有体験
  • 旅の記録が資産化し、リピート・帰省の再利用へ

優先度 05再訪トリガー

プッシュ通知が、間欠的な利用を習慣に変える

「明日の集合は9時」を前日に通知。再訪トリガーはリテンションの生命線です。ネイティブ化の前に PWA で十分戦えます。旅行先は電波が弱いため、オフライン対応と併せて“当日開けるアプリ”に。

  • スケジュール変更・当日リマインドで確実に呼び戻す
  • PWA なので配信ストア審査なしで即導入可能
  • オフライン対応で「現地で開けない」を解消
